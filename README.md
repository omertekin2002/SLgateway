# SignLoop Chat Service (moved)

This repository is archived. The gateway now lives in the SignLoop monorepo:

- **Gateway app:** [`apps/gateway`](https://github.com/omertekin2002/SignLoop/tree/main/apps/gateway). It has the same `/v1/chat` API and the same Render service, `signloop-chat-api`.
- **Shared chat engine:** [`packages/chat-engine`](https://github.com/omertekin2002/SignLoop/tree/main/packages/chat-engine), also used by the SignLoop web app.

The full history of this repository was imported into `apps/gateway` with `git subtree`. Render deployed this repository's last version, `0987fe2`, until 2026-10-24.
